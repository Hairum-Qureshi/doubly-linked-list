This project consists of 4 main functionalities:
1. Adding a student to the doubly linked list
2. Removing all students that share a specific last name that the user inputs
3. Printing out the list from oldest to newest
4. Printing out the list in reverse order (from newest to oldest)

To run the file, enter the following command:
`make slist`

To remove the `slist.o` file, run:
`make clean`
